# autocut — 動画の自動編集ツール

2つの道具が入っています。少しずつ機能を足していきます。

**autocut.py — 自動編集**（無音・「えー」「あの」・言い直しをカットし、字幕を入れて書き出す）

| 段階 | 内容 | 状態 |
|---|---|---|
| 1 | 無音カット ＋ YouTube用（16:9）書き出し ＋ カット一覧 | ✅ できています |
| 2 | 言い間違い・「えー」「あの」のカット（文字起こし） | ✅ できています |
| 3 | 字幕（テロップ）と .srt | ✅ できています |
| 4 | 縦（9:16）・正方形（1:1 / 4:5）の書き出し | これから |
| 5 | Final Cut Pro 用タイムライン（FCPXML） | これから |

**clip.py — 切り抜き**（長い動画からショート動画を何本も作る）→ 使い方は[このページの下のほう](#切り抜きclippy)

| 段階 | 内容 | 状態 |
|---|---|---|
| 1 | 喋りの動画から切り抜き候補を探して一覧にする | ✅ できています |
| 2 | 選んだ候補を書き出す（縦・横・正方形を選べる、人物に合わせて自動トリミング） | ✅ できています |
| 3 | タイトルテロップ・字幕・投稿用テキスト | ✅ できています |
| 4 | ダンス・ライブ映像の見せ場探し（音と動きから。無料） | ✅ できています |

## 準備（最初の1回だけ）

「ターミナル」というアプリを使います（Launchpad で「ターミナル」と検索）。
下のコマンドをコピーして貼り付け、Enter を押してください。

### 1. Macの種類を確認する

```bash
uname -m
```

`arm64` と出たら Apple Silicon、`x86_64` と出たら Intel です。
（今の段階ではどちらでも同じ手順です。次の段階で使うので、結果を教えてください）

### 2. Homebrew を入れる

Homebrew は、Macに無料ツールを入れるための道具です。すでに入っていれば飛ばしてください。

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

途中でMacのパスワードを聞かれます（入力しても画面には何も表示されませんが、打てています）。
終わったあと、画面の最後に「Next steps」としてコマンドが表示されたら、それもコピーして実行してください。

### 3. ffmpeg を入れる

ffmpeg は、動画を切ったり変換したりする無料ツールです。

```bash
brew install ffmpeg
```

### 4. このツールをダウンロードする

GitHub のこのページで、緑の「Code」ボタン →「Download ZIP」を選び、
ZIPを開いてできたフォルダを、分かりやすい場所（例: 書類フォルダ）に置いてください。

## 使い方

ターミナルに、次の順で入力します。

1. `python3 ` と打つ（最後に半角スペース）
2. `autocut.py` のファイルをターミナルの画面にドラッグ＆ドロップ
3. 動画ファイルをターミナルの画面にドラッグ＆ドロップ
4. Enter

こんな1行になります:

```bash
python3 ~/Documents/kairikomiya/autocut.py ~/Movies/test.mp4
```

初めて実行したとき「コマンドライン・デベロッパツールが必要です」と出たら、「インストール」を押して、終わってからもう一度実行してください。

元の動画と同じ場所に `（動画の名前）_autocut` というフォルダができ、中に次の2つが入ります。
元の動画は変更されません。

- `〜_youtube.mp4` … 無音をカットした動画（1920×1080）
- `〜_cuts.csv` … どこをカットしたかの一覧（Numbers で開けます）

## カットの強さを調整する

`config.toml` をテキストエディットで開き、数字を変えて保存して、もう一度実行します。

| 困りごと | 直し方 |
|---|---|
| 話している途中まで切られる | `threshold_db` を小さく（例: -35 → -42） |
| 無音があまり切られない | `threshold_db` を 0 に近づける（例: -35 → -30） |
| テンポが速すぎる・息苦しい | `pad_before` `pad_after` を大きく、または `min_silence` を大きく |
| まだ間が長い | `min_silence` を小さく（例: 0.4） |

実行すると「この動画の音量: 平均 ○dB / 最大 ○dB」と表示されます。
`threshold_db` は、平均より 5〜15 くらい小さい数字が目安です。

動画を書き出さずに、カット一覧だけ素早く作って試すこともできます（最後に ` --list-only` を足す）:

```bash
python3 ~/Documents/kairikomiya/autocut.py ~/Movies/test.mp4 --list-only
```

## 言い間違い・「えー」「あの」のカット

`setup.sh` を実行してあれば（文字起こしツールが入っていれば）、いつもの1行で自動的に行います。
無音カットに加えて、文字起こしをして次のものを見つけます。

| 理由 | カットするもの | 例 |
|---|---|---|
| えー・あの | 「えー」「あの」「うーん」などのつなぎの言葉 | 「**えー、**今日は」 |
| 繰り返し | すぐ同じ言葉を言い直したときの1回目 | 「**これは、**これは大事」 |
| 言い直し | 言いかけてやめて、次で言い直したときの言いかけた方 | 「**このコードの**」→「このコード進行を…」 |
| 声なし | 喋っていない間（BGM が流れていて、音量では無音と分からないとき） | |

- 「あの人」の「あの」のように、前後に「、」や間（ま）がないものは残します。
- 文字起こしに時間がかかるので、最初の1回は動画の長さの 1/10〜同じくらいかかります。2回目からは保存した文字起こしを使うのですぐです。
- `〜_autocut` フォルダに `〜_文字起こし.txt` もできます。
- カット一覧の「内容」の列に、カットした言葉が入ります。カットしたくないものは「いいえ」にしてください。
- 速く無音カットだけしたいときは、最後に ` --quick` を足します。
- カットする言葉の一覧や、どれをカットするかは `config.toml` の `[cut]` で変えられます。

もう一度実行すると、前のカット一覧は `〜_cuts_old1.csv` として残ります。

## 字幕

文字起こしをしたとき（`--quick` を付けないとき）は、字幕も自動で入ります。

- 字幕は、カットしたあとの動画の時間に合わせてあります。カットした「えー」などは、字幕からも消えます。
- 画面の下に焼き込み、`〜_autocut` フォルダに `〜_字幕.srt` も作ります。
- 大きさ・色・位置は `config.toml` の `[subtitle]` で変えられます（横の動画の位置は `position_yoko`）。
- 焼き込まずに `.srt` だけ作りたいとき（YouTube に字幕ファイルとしてアップロードする場合）は、
  `config.toml` の `[youtube]` の `burn_subtitles` を `false` にします。
- 字幕を入れないときは、最後に ` --no-subs` を足します。

字幕は、実際に声が出ている時間に合わせて出します（喋り出す前の無音に字幕が出ないようにしています）。

### 字幕の文字を直す

文字起こしは聞き間違いをすることがあります（「国立」が「確率」に、「石川県人」が「石川賢人」になる、など）。
直し方は3つあります。

**A. 置き換え表（いちばん手軽。字幕にだけ効く）**

`config.toml` の `[subtitle]` の `replace` に「間違い→正しい言葉」を書いて、もう一度実行します。
文字起こしのやり直しはいらないので、すぐ終わります。

```toml
replace = ["確率競技場→国立競技場", "石川賢人→石川県人"]
```

書いた言葉は全部置き換わります（「確率→国立」と書くと「確率論」も「国立論」になります）。
前後の言葉も含めて書くと安全です。

**B. 言葉のヒント（次の文字起こしから効く）**

`config.toml` の `[transcribe]` の `hints` に、動画に出てくる人の名前・地名・専門用語を書いておくと、
文字起こしで正しく書かれやすくなります。

```toml
hints = ["国立", "石川県人", "星稜高校"]
```

もう文字起こしした動画でやり直すときは、`〜_autocut` フォルダの `〜_words.json` を捨ててから実行します。

**C. 字幕ファイルを直接直す（1か所だけ直したいとき）**


1. `〜_字幕.srt` をテキストエディットで開いて文字を直し、別の名前で保存する（例: `字幕_直し.srt`）。
   「編集」→「検索」→「検索と置き換え」を使うと、同じ間違いをまとめて直せます
2. 最後に ` --cuts ` とカット一覧、` --srt ` と直した字幕をドラッグ＆ドロップして実行する

```bash
python3 ~/Desktop/動画自動編集ツール/kairikomiya/autocut.py （動画） --cuts （〜_cuts.csv） --srt （字幕_直し.srt）
```

字幕を直したあとでカット一覧を変えると、時間がずれます。カットを先に決めてから、字幕を直してください。

## カットしすぎた部分を戻す

1. `〜_cuts.csv` を Numbers で開く
2. 戻したい行の「カットする」を `はい` → `いいえ` に書きかえる
3. 「ファイル」→「書き出す」→「CSV」で保存する（別の名前でOK）
4. 最後に ` --cuts ` と直したCSVを足して実行する（CSVもドラッグ＆ドロップできます）

```bash
python3 ~/Documents/kairikomiya/autocut.py ~/Movies/test.mp4 --cuts ~/Movies/test_autocut/test_cuts.csv
```

「開始」「終了」は元の動画での時間です。「開始秒」「終了秒」の列は消さないでください。

# 切り抜き（clip.py）

長い動画（10〜60分）から、ショート動画（30〜60秒）にできそうな部分をAIが探して、一覧にします。
今の段階では**喋りの動画**が対象で、**一覧を作るところまで**です（動画の書き出しは次の段階）。

仕組み: ①Macの中で文字起こし（無料）→ ②文字起こしをAI（Claude）に読んでもらい、候補を選んでもらう

②のやり方は2通りあります。

| | 無料の方法（おすすめ） | 自動の方法 |
|---|---|---|
| やり方 | 依頼文を Claude アプリに自分で貼り付け、返事をコピーする | ツールが Claude API を直接呼ぶ |
| 料金 | かからない（お使いの Claude のプランの範囲内） | 60分の動画1本で 50〜100円くらい |
| 手間 | 貼り付けとコピーが1回ずつ | コマンド1回だけ |

`api_key.txt` というファイルがフォルダに無ければ、無料の方法で動きます。

## 準備（最初の1回と、ツールを新しくしたとき）

上の「準備」1〜4（Homebrew・ダウンロード）が済んでいる前提です。

ターミナルに `bash ` と打ち（最後に半角スペース）、`setup.sh` をドラッグ＆ドロップして Enter。

```bash
bash ~/Documents/kairikomiya/setup.sh
```

文字起こしツール（whisper-cpp）などが入ります。最初は数分かかります。

### ツールを新しくするとき

1. 新しい ZIP をダウンロードして開く（古いフォルダは、新しい版で1回動かすまで消さずに残しておいてください。
   1.6GB の文字起こし用モデルを、古いフォルダから自動で引き継ぎます）
2. 新しいフォルダの `setup.sh` を、上と同じ方法で実行する（2回目以降はすぐ終わります）
3. `config.toml` を書きかえていた場合は、新しいフォルダの `config.toml` にも同じように書きかえる

## 使い方（無料の方法）

### 1. 文字起こしをして、依頼文を作る

`python3 ` → `clip.py` をドラッグ＆ドロップ → 動画をドラッグ＆ドロップ → Enter。

```bash
python3 ~/Documents/kairikomiya/clip.py ~/Movies/talk.mp4
```

- 初回だけ、文字起こし用のモデル（約1.6GB）を自動でダウンロードします。
- 文字起こし中は、聞き取った文章が画面に流れます。60分の動画で数分〜十数分です。
- 終わると、Claude への依頼文が自動でコピーされた状態になります。

### 2. Claude アプリに選んでもらう

1. Claude アプリ（または claude.ai）で新しいチャットを開く。モデルは Opus など賢いものがおすすめ
2. 入力欄で ⌘V（貼り付け）して送信する
3. 返事のコードブロック（灰色の枠）の右上にある「コピー」を押す

### 3. 一覧を作る

1 と同じコマンドの最後に ` --paste` を足して実行します（ターミナルで ↑ キーを押すと、前のコマンドが出てきます）。

```bash
python3 ~/Documents/kairikomiya/clip.py ~/Movies/talk.mp4 --paste
```

元の動画と同じ場所の `（動画の名前）_clips` フォルダに、次のファイルができます。

- `〜_candidates.csv` … 切り抜き候補の一覧（Numbers で開けます）
- `〜_transcript.txt` … 文字起こしの全文
- `〜_prompt.txt` … Claude への依頼文（コピーし直したいときに使えます）

選び直してほしいときは、Claude のチャットで「もっと笑える部分を」「別の候補を10本」などと頼んで、
返事をコピーして 3 をもう一度実行すれば一覧が作り直されます（前の一覧は `〜_old1.csv` として残ります）。

## 使い方（自動の方法・有料）

貼り付けの手間をなくしたい場合だけ。Claude API は Claude.ai のプランとは別の支払いで、
最初に5ドル分（最低額）のクレジットを買う必要があります。

1. <https://platform.claude.com> を開いて、アカウントを作る（またはログイン）
2. 「Billing」でクレジットを買う
3. 「API Keys」→「Create Key」でキーを作り、「Copy」を押す。キーは他の人に見せたり、チャットに貼ったりしないでください
4. コピーした直後に、ターミナルで次を実行する（フォルダの場所は自分のものに合わせてください）

```bash
pbpaste > ~/Documents/kairikomiya/api_key.txt
```

以後は `python3 clip.py 動画` の1回だけで一覧までできます。実行のたびに、使った量と料金の目安が表示されます。
選び直すときは最後に ` --redo` を足します。無料の方法に戻すときは `api_key.txt` を削除します。

## 候補の一覧の見方

| 列 | 内容 |
|---|---|
| 使う | `はい` / `いいえ`。`はい` のものだけ書き出します |
| 開始・終了 | 元の動画での時間。直したいときは `12:34.5` か `1分23秒` のように書きかえます |
| 形 | 空ならコマンドで指定した形。この候補だけ変えたいときに `縦` `横` `正方形` `4:5`（`縦 横` で両方） |
| 位置 | 空なら人物に合わせて自動。うまくいかないときに 0〜100 の数字（0=左端、50=中央、100=右端） |
| タイトル案 | 動画の冒頭に出すテロップの案 |
| 冒頭のセリフ | 切り抜きの最初の一言（文字起こしのまま） |
| 要約・選んだ理由 | 内容と、AIがここを選んだ理由 |
| 説明文・ハッシュタグ | 投稿するときの文章の案 |

おすすめ度が高い順に並んでいます。まずは開始・終了の時間を元の動画で再生して、
「ここで始まってここで終わるのは自然か」「選び方は好みに合うか」を見てみてください。

## 書き出す

一覧を Numbers で開いて「使う」「開始」「終了」などを直したら、「ファイル」→「書き出す」→「CSV」で
**同じ名前・同じ場所に上書き保存**します（`〜_candidates.csv`）。そのあと、最後に ` --export` と形を足して実行します。

縦だけ（ショート / TikTok / リール）:

```bash
python3 ~/Documents/kairikomiya/clip.py ~/Movies/talk.mp4 --export tate
```

縦と横の両方:

```bash
python3 ~/Documents/kairikomiya/clip.py ~/Movies/talk.mp4 --export tate yoko
```

使える形: `tate`（縦 9:16）/ `yoko`（横 16:9）/ `square`（正方形 1:1）/ `feed`（4:5）

`_clips` フォルダの中の `書き出し` フォルダに、`talk_01_タイトル_縦.mp4` のような名前でできます。

- 縦や正方形にするときは、顔（見つからなければ全身）を探して、その人が画面に入る位置で切り出します。
  見つからないときは中央で切り出します。ずれていたら一覧の「位置」に数字を書いて、もう一度書き出してください。
- 元が縦撮りの動画を横で書き出すと、上下を切って横長にします（黒い帯は付けません）。
- 同じ候補を書き出し直すと、前のファイルは上書きされます。
- 別の名前で保存した一覧を使うときは、最後に ` --list ` と CSV をドラッグ＆ドロップで足します。

## ダンス・ライブ映像の見せ場探し（--dance）

喋りのない動画（ダンス・パフォーマンス・ライブ）は、文字起こしの代わりに、
**音の大きさ・ビートの強さ・映像の動きの大きさ**を0.1秒ごとに測って、盛り上がっている部分を探します。
AI は使わないので無料で、Claude への貼り付けもいりません。

```bash
python3 ~/Desktop/動画自動編集ツール/kairikomiya/clip.py ~/Movies/dance.mp4 --dance
```

- 盛り上がっている順に、5〜12本の候補が一覧（`〜_candidates.csv`）に入ります。
- `〜_見せ場グラフ.png` で、動画全体の盛り上がり（青い線）と、選ばれた場所（オレンジ）を見られます。
- カメラの切り替え（画面全体が一気に変わる瞬間）は、動きとして数えません。
- 始まりと終わりは、近くのビート（音が強く鳴った瞬間）に合わせます。
- タイトルは空です。テロップを入れたいときは、一覧の「タイトル案」に書いてください。

あとは喋りの動画と同じで、一覧を確認してから ` --export tate yoko` で書き出します（字幕は入りません）。

縦に切り出すときは、顔や全身が見つからなければ「映像の中でいちばん動いている場所」を中心にします。
人がステージを左右に移動するときは、カメラが追いかけるように、切り出す位置をゆっくり動かします
（`config.toml` の `[crop]` で止められます）。

盛り上がりの決め方は `config.toml` の `[dance]` で変えられます（本数・長さ・音と動きのどちらを重視するか）。

## テロップと字幕

`--export` で書き出すと、自動で次のものが入ります。

- **タイトルテロップ**：最初の2秒、画面の上のほうに大きく出ます。文字は一覧の「タイトル案」です。
  改行したい位置があるときは、Numbers のセルの中で option + return を押して改行してください。
- **字幕**：文字起こしから作り、画面の下のほうに出ます。
- **投稿用テキスト**：`書き出し` フォルダの `〜_投稿用テキスト.txt` に、候補ごとのタイトル・説明文・ハッシュタグがまとめて入ります。

字幕を入れたくないときは、最後に ` --no-subs` を足します。

### 字幕の文字を直す

文字起こしは聞き間違いをすることがあります。直したいときは、次の手順で書き出し直します。

1. `_clips` フォルダの中の `字幕` フォルダを開く（候補ごとに `〜_01.srt` のようなファイルがあります）
2. 直したい `.srt` を右クリック →「このアプリケーションで開く」→「テキストエディット」で開く
3. 文字だけを書きかえて保存する（番号と `00:00:01,200 --> 00:00:03,400` の行は消さないでください）
4. もう一度 `--export` で書き出す

直した字幕はそのまま使われます。ただし、一覧でその候補の「開始」「終了」を変えると、字幕は作り直しになります
（前の字幕は `〜_old1.srt` として残ります）。

### 見た目を変える

`config.toml` の `[title]` と `[subtitle]` で、文字の大きさ・色・ふち・帯・位置・フォント・タイトルを出す秒数を変えられます。

## 調整

`config.toml` の `[clips]` で変えられます。

- 本数（`count_min` `count_max`）、長さ（`length_min` `length_max`）
- `channel_info` … チャンネルの説明を書くと、視聴者に合わせて選ぶようになります
